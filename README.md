# Omo-Oba Boa Olugbewesa — Birthday Biography

## Run locally

```bash
npm install
npm run dev
```

Open the **Local** URL in your browser. On your phone (same Wi‑Fi), use the **Network** URL shown in the terminal.

If `npm run dev` fails with a `styleText` / Node error, run:

```bash
nvm use
npm run dev
```

This project works on Node 18+, and prefers Node 22 via `.nvmrc`.

## Build for QR / hosting

```bash
npm run build
```

Deploy the `dist` folder, then put that URL in the party QR code.

## Site map

- `/` — home dashboard (previews + Show more)
- `/about` — full about page
- `/journey` — full timeline
- `/gallery` — full photo gallery
- `/tributes` — full tributes
